## 1순위: 시연 루프

시연 영상은 기능 목록보다 한 번에 이해되는 흐름이 중요하다.

1. 타이틀에서 시작
2. 필드 진입
3. 체크포인트 저장
4. 체크포인트 휴식 메뉴에서 인벤토리 / 저장 / 레벨업 확인
5. 필드 몬스터 처치로 경험치 획득
6. 보스방 접근
7. 보스 패턴 회피 / 패링 / 그로기
8. 처형 또는 마무리 공격
9. 보스 처치 후 보상 또는 다음 구역 개방
10. CMD 최종 보스 클리어 장면

## 2순위: 제출 전 직접 확인

- `L_Runtime_Field`에서 플레이어가 바닥 아래로 떨어지지 않는지 확인
- 각 보스 아레나 트리거가 의도한 보스만 켜는지 확인
- 보스 체력바가 시작/종료 시 정상 표시되는지 확인
- 플레이어 사망 후 체크포인트 리스폰과 보스 재도전이 되는지 확인
- 플레이어 사망 위치에 무덤이 생기고 남은 경험치만 드롭되는지 확인
- 무덤 회수 시 드롭 경험치가 복구되는지 확인
- 필드 몬스터가 피격 시 경직되고 공격 중이면 공격이 취소되는지 확인
- 인벤토리 `I`, 핫바 `Q/E/R`, 일시정지 `Esc` 동작 확인
- 인벤토리 탭 분류와 아이템 상세 표시가 깨지지 않는지 확인
- 체크포인트 휴식 메뉴에서 레벨업 후 경험치가 정확히 차감되는지 확인
- 저장 후 Continue로 같은 레벨에 복귀하는지 확인
- 바닥/벽 텍스처와 CMD 왕좌, 안개문, 물약, 상징 나무, 제단, 체크포인트 메쉬가 월드그리드/기본 큐브로 돌아가지 않았는지 확인
- 다른 PC 또는 새 클론에서 에셋 누락 없이 열리는지 확인

## 3순위: 포트폴리오 설명 포인트

- `ABRBossBase`: HP, Groggy, Phase, Execution 공통 상태 관리
- `ABRPatternBossBase`: 거리/페이즈 기반 패턴 선택과 전조/공격 처리
- `ABRBossArenaTrigger`: 보스전 시작, HUD 연결, 클리어 처리
- `AExceptionCharacter`: 공격, 회피, 패링, 처형, 리스폰
- `AExceptionCharacter`: 경험치 보유, 레벨업 비용 처리, 사망 시 미사용 경험치 드롭
- `ABRPlayerGraveMarker`: 사망 위치 무덤, 경험치 회수
- `ABRCheckpoint`: 체크포인트 저장, 회복, 휴식 메뉴 진입
- `UBRInventoryComponent`: 슬롯 기반 아이템 데이터와 저장 연동
- `UBRSaveGameSubsystem`: 레벨, 위치, 스탯, 인벤토리, 히든 루트 저장
- `UBRHiddenStorySubsystem`: Nel 요청, 로그 파편, 히든 엔딩 조건
