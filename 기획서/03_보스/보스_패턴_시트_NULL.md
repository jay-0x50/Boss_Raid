## 3. 패턴 구조

모든 패턴은 기존 보스와 동일하게 `텔레그래프 -> 히트 판정 -> 후딜/복귀` 구조를 따른다.
NULL은 텔레그래프를 몸동작보다 **터미널 명령어 출력**으로 먼저 보여준다.

```text
> COMMAND
> TARGET: Hendel
> RUN
```

## 6. 구현 메모

- C++ 1차 구현에서는 `Melee`, `Dash`, `AOE` 타입으로 축약하고, `>FORK`, `>KILL -9`, `>REWRITE`는 블루프린트 이벤트/VFX에서 확장한다.
- 명령어 텔레그래프는 보스 HUD 또는 화면 우측 상단 시스템 로그 UI와 연결한다.
- 최종전은 `Vritra` 처치 후 열린 CMD 구역에서 시작한다.
