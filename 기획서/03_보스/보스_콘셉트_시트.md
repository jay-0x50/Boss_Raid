# 보스 콘셉트 시트

> **목적:** `Exception`의 보스들이 어떤 프로그래밍 언어/개발 도구에서 출발했는지, 그리고 이를 액션 보스전으로 어떻게 바꿀지 정리한다.

## 1. 전체 콘셉트

플레이어는 오류가 폭주한 런타임 내부로 진입하고, 각 보스는 특정 언어/도구의 상징이 변형된 예외 개체로 등장한다.

- 보스는 단순 패러디가 아니라, 각 언어/도구의 이미지와 개발자 밈을 전투 패턴으로 번역한다.
- MVP에서는 **보스 3체 (Serpent.py → Fatal Elephant → NULL)** 를 완성한다.
- 포트폴리오에서는 "콘셉트가 시스템으로 연결된다"는 점을 보여주는 것이 핵심이다.

| 순서 | 보스명 | 모티브 | 실루엣 | 역할 |

## 3. 1보스 — Serpent.py (Python)

### 핵심 이미지

- 파이썬 로고의 **파란 뱀 + 노란 뱀**이 합쳐진 쌍두사
- 두 마리가 하나의 몸체를 공유하는 듀얼 헤드 구조
- 파랑(얼음/번개) vs 골드(불/용암) 색 대비

### 역할

처음 만나는 Primordial Exception. 전투 루프(패링 → 그로기 → 처형)를 학습시키는 튜토리얼 역할.

### 패턴 방향

| 페이즈 | 패턴 | 키워드 |
|---|---|---|
| Phase 1 | Tail Sweep Combo | 근거리 콤보. 패링 유도. |
| Phase 1 | Coil Slam | 광역 낙하. 예고 데칼 학습. |
| Phase 2 | Shadow Dash | 고속 돌진. 측면 회피 학습. |
| Phase 2 | Syntax Venom | 독 장판. 공간 읽기 학습. |

### 처치 후 로그

> *"왜 너는 우리를 지우려 하는가. 우리가 없었다면 너도 없었다."*

## 4. 2보스 — Fatal Elephant (PHP)

### 핵심 이미지

- PHP 마스코트 코끼리를 모티브로 한 거대한 존재
- 수십 년 된 레거시 코드처럼 켜켜이 쌓인 오류들이 갑옷처럼 굳어있는 형태
- 묵직하고 느려 보이지만 **갑자기 폭발적으로 빠른 돌진**이 특징
- PHP 특유의 "오래됐는데 안 죽는" 이미지 — 낡은 갑옷 틈새로 오래된 코드 라인이 흘러나옴

### 비주얼

- 거대한 코끼리형 몸체. 높이는 Serpent.py의 1.5배 이상
- 몸 전체가 **녹슨 서버 랙/케이블**로 뒤덮인 느낌
- 코(트렁크) 부분은 케이블 다발로 대체
- 눈은 PHP 로고의 보라색 발광

### 역할

2번째 보스. Serpent.py에서 배운 루프를 **더 빡빡한 상황**에서 실전 적용하는 단계.

느릿느릿 움직이다 갑자기 폭발하는 패턴으로 "방심은 죽음"을 가르친다.

### 패턴 방향

| 페이즈 | 패턴명 | 타입 | 키워드 |
|---|---|---|---|
| Phase 1 | Legacy Charge | Smash | 예고 없는 고속 돌진. 측면 회피 필수. |
| Phase 1 | Deprecation Stomp | AOE | 발구르기 광역 충격파. 예고 데칼 있음. |
| Phase 2 | Fatal Error | Smash | HP 50% 이하에서만 사용. 광폭 3연타. |
| Phase 2 | Overflow | AOE / Zone | 전장에 오염 케이블 장판 설치. 이동 제한. |

### 처치 후 로그

> *"너를 만든 자를 알고 있다. 그는 우리를 깨웠고, 너를 보냈다. 이유를 묻지 않았느냐."*

## 5. 최종보스 — NULL

### 핵심 이미지

인간형 실루엣. 그러나 **완전히 렌더링되지 않은** 느낌 — 와이어프레임이 깜빡이고, 윤곽이 흔들리며, 일부 부위가 픽셀화된다. The Runtime 자체가 의식을 가지게 된 존재.

### 비주얼

- **얼굴:** 반쯤 가려진 후드. 눈 위치에 터미널 커서(`█`)가 깜빡인다
- **몸:** 검은 로브 위로 흰 명령어 텍스트가 실시간으로 흘러내림
- **무기:** 없음. 허공에 명령어를 타이핑하면 그것이 공격으로 실행됨
  - `>SLASH`, `>EXECUTE`, `>FORK` 등 공격마다 텍스트가 먼저 표시됨
- **피격 시:** 몸 일부가 글리치되거나 픽셀화. 화면에도 글리치 이펙트

### 역할

반전의 핵심. **Hendel을 만든 자이자 봉인을 푼 자**. 모든 스토리의 원흉.

NULL을 처치하면 The Runtime이 어떻게 될지 — 플레이어가 판단한다.

### 패턴 방향

| 페이즈 | 패턴명 | 타입 | 키워드 |
|---|---|---|---|
| Phase 1 | `>SLASH` | Normal | 명령어 소환 근거리 타격. 패링 가능. |
| Phase 1 | `>EXECUTE` | Smash/AOE | 좌표 지정 수직 폭발. 예고 타이핑 있음. |
| Phase 1 | `>MOVE` | Smash | 텔레포트 후 즉시 근접 타격. |
| Phase 2 | `>FORK` | 특수 | NULL 분열. 두 개의 분열체 동시 처치 필요. |
| Phase 2 | `>KILL -9` | 특수 | Hendel 조작 일시 차단 (1~2초). |
| Phase 2 | `>REWRITE` | 환경 변조 | 전투 공간 일부 지형/판정 변경. |

### 보스명 정리

| 항목 | 내용 |
|---|---|
| 보스명 | **NULL** |
| 부제 | *The First Command* |
| 모티브 | CMD / Terminal |
| 본질 | The Runtime의 의식. 모든 명령의 근원. |
| 처형 후 마지막 로그 | `> PROCESS: NULL — TERMINATED` |

## 8. 비주얼 가이드

- 과하게 귀엽게 만들기보다, 원본 아이콘의 특징을 "보스 실루엣"으로만 남긴다.
- 색은 언어/도구의 대표색을 참고하되, 전투 가독성을 우선한다.
- 텔 동작은 동물적(또는 기계적) 움직임으로 읽히게 만들고, 실제 판정은 명확한 기하 형태로 관리한다.
- NULL은 **인간형이지만 인간이 아님**을 비주얼에서 명확히 전달해야 한다.

## 9. 구현 메모

- 보스 콘셉트는 BP/애니메이션 레이어에서 바뀌어도 C++ 코어는 재사용 가능해야 한다.
- `BossSkillData`에 `SkillTag`, `AttackType`, `DamageProfileId`, `MontageKey`를 넣어 보스별 패턴 교체가 가능하게 설계한다.
- MVP 이후 다른 언어 보스를 추가할 때는 같은 `AExBossCharacter`와 `UExBossSkillComponent` 구조를 유지한다.
- NULL의 `>KILL -9` 패턴처럼 플레이어 입력을 차단하는 효과는 `DisableInput` + 타이머로 구현.
