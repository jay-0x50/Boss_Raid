## 3. 공통 규칙

모든 패턴은 아래 3단계 구조를 반드시 포함한다.

- **텔(예고 동작):** 플레이어가 "피해야 한다"는 것을 인지할 수 있는 예고 모션
- **위험 구간(히트 프레임):** 실제 판정이 발생하는 구간
- **리커버리(후딜):** 대응 성공 시 딜 찬스를 만드는 구간

공격 타입 태그:

- `Normal` — 패링 가능
- `Smash` — 패링 불가, 회피 권장
- `AOE` — 범위기, 위치 이동 유도
- `Zone` — 지속 장판, 공간 압박

## 4. 패턴 발동 철학

쿨타임은 밸런스 안전장치일 뿐, **실제 발동 타이밍은 AI가 상황을 보고 판단**한다.

- 쿨타임 종료 = **Ready 상태** (발동 후보에 포함)
- Ready 상태에서도 아래 조건을 모두 만족해야 발동:
    - 사거리/각도가 유리한 상황
    - 플레이어가 회피 여지가 낮다고 추정될 때 (연속 공격 중, 스태미나 고갈 등)
    - 직전에 같은 패턴을 쓰지 않았을 때 (반복 페널티)
- 후보 패턴들 중 **가중 랜덤(Weighted Random)** 으로 최종 선택

## 5. Phase 1 패턴

### P1-1) Tide Surge `Normal`

> "거대한 몸을 기울여 측면에서 해일처럼 밀어붙인다"

| 항목 | 수치/내용 |
| --- | --- |
| Trigger 거리 | < 300 |
| Cooldown | 4s |
| AttackType | Normal (패링 가능) |
| GroggyDamage | +15 |
| Damage | 25 |
| HitStop | 0.10s |
| ReactionType | Heavy_Hit |

**텔 (0.4s)**
- 거대한 몸통을 한쪽으로 기울이며 척추 지느러미가 일제히 세워짐
- 몸 측면의 회로 패턴이 강하게 발광 (시각 신호)

**히트 프레임**
- 측면 몸통 전체가 플레이어 방향으로 쓸어내리는 판정 `0.2s`
- 히트 성공 시 Heavy_Hit 넉백 적용

**리커버리 (0.6s)**
- 몸을 반대 방향으로 복귀하는 모션. 측면이 잠깐 노출됨

**대응 의도**
- 패링 성공 시 그로기 +15 (고보상)
- 뒤로 물러나 회피 (안전하지만 딜 찬스 없음)
- 리커버리 구간에 측면 반격 가능

### P1-2) Null Field `AOE / Zone`

> "바닥에 NULL 데이터 장판을 깔아 플레이어의 행동을 제한한다"

| 항목 | 수치/내용 |
| --- | --- |
| Trigger 거리 | 200 ~ 700 |
| Cooldown | 9s |
| AttackType | AOE + Zone (패링 불가) |
| GroggyDamage | 0 |
| Damage | 장판 초당 10 (3초 지속) |
| 스태미나 디버프 | 장판 위에서 스태미나 회복 정지 |
| 장판 반경 | 각 장판 180, 최대 2개 동시 |

**텔 (0.6s)**
- 바닥에 데이터베이스 테이블 격자 형태의 경고 패턴이 서서히 채워짐
- 사이안 색으로 빛나며 발동 지점 안내

**히트 프레임**
- 경고 영역에 NULL 장판 생성 (Decal + Collision Box)
- 장판은 3초간 지속, 위에 있으면 지속 피해 + 스태미나 회복 정지

**리커버리 (0.4s)**
- 보스 자체 후딜은 짧음. 장판이 압박을 지속하므로 다음 행동 가능

**대응 의도**
- 장판 범위 밖으로 이동
- 공간 읽기 강요 — 무지성 근접 딜링을 막는 장치
- 장판 사이 안전지대를 찾으며 락온 유지

## 6. Phase 2 진입 — Deadlock Sequence

> HP 50% 이하 최초 도달 시 1회 발동

| 항목 | 내용 |
| --- | --- |
| Trigger | `CurrentHP <= MaxHP * 0.5` 최초 1회 |
| 무적 구간 | 진입 연출 전 구간 (약 4s) |
| BT 처리 | 현재 태스크 `Abort(Self)` → Deadlock 서브트리 실행 |
| 이후 | P2 전용 서브트리로 전환. MoveSpeed 350 → 500. 장판 수 최대 3개로 증가 |

**연출 순서**
```
보스 HP 50% 도달
    ↓
BT Abort → 무적 활성화
    ↓
포효 몽타주 재생 (AM_Boss_Deadlock)
    - 척추 지느러미가 전부 세워지며 전신에서 사이안 이펙트 폭발
    - 몸 전체의 회로 패턴이 일시적으로 꺼졌다 과부하처럼 재점화
    ↓
Niagara VFX: 데이터 파편 + 회로 발광 강화
보스 스케일 소폭 증가 (시각적 광폭화 표현)
    ↓
무적 해제 → P2 BT 활성화
```

## 7. Phase 2 패턴

### P2-1) Data Crush `Smash`

> "거대한 꼬리를 위에서 아래로 내리찍어 충격파를 발생시킨다"

| 항목 | 수치/내용 |
| --- | --- |
| Trigger 거리 | < 400 |
| Cooldown | 5s |
| AttackType | Smash (패링 불가) |
| GroggyDamage | 0 |
| Damage | 직격 55 / 충격파 30 |
| HitStop | 0.20s |
| ReactionType | 직격 Knockback / 충격파 Heavy_Hit |
| 충격파 반경 | 350 |

**텔 (0.5s)**
- 꼬리를 높이 들어 올리고 척추 지느러미가 뒤로 접힘
- 바닥에 충격파 예고 원형 데칼 표시 (서서히 사이안으로 채워짐)

**히트 프레임**
- 꼬리 착지 순간 `0.1s` 직격 판정 (반경 120)
- 착지 직후 `0.2s` 충격파 AOE 확장 (반경 350)

**리커버리 (0.8s)**
- 착지 후 자세 재정비. 긴 후딜로 반격 창 제공

**대응 의도**
- 예고 원 밖으로 이동 후 후딜에 반격
- "한 번 크게 피하고 딜한다"는 학습 유도

### P2-2) Transaction Loop `AOE / Zone Control`

> "교착 상태에 빠진 트랜잭션처럼, 장판을 연속으로 깔아 공간 전체를 잠식한다"

| 항목 | 수치/내용 |
| --- | --- |
| Trigger 조건 | 플레이어가 보스 근거리(< 250)에서 3초 이상 유지 시 |
| Cooldown | 12s |
| AttackType | Zone (이동 회피 권장) |
| GroggyDamage | 0 |
| Damage | 장판 초당 12 (3~4초 지속) |
| 스태미나 디버프 | 장판 위에서 스태미나 회복 딜레이 +1.5s |
| 장판 반경 | 각 장판 150, 최대 3개 순차 생성 |

**텔 (0.8s)**
- 몸 전체의 회로 패턴이 빠르게 명멸하며 불안정해 보이는 모션
- 바닥에 3개의 장판 예고 패턴이 순차적으로 표시됨

**히트 프레임**
- 예고 순서대로 3개의 장판이 0.3s 간격으로 순차 생성
- 각 장판은 3~4초 지속, 겹치는 구간에 안전지대 최소화

**리커버리**
- 보스 자체 후딜 없음 (0.2s). 장판이 전투 공간 압박을 지속

**대응 의도**
- 장판 생성 순서를 읽고 마지막 안전지대 예측
- "공간 전체가 잠기기 전에 빠져나온다"는 긴박감 연출

## 10. 선택 패턴 아이디어 (Nice / 확장)

### P2-3) Void Breach `Smash / AOE`

- **컨셉:** 보스가 허공으로 잠깐 사라졌다가 플레이어 발밑에서 폭발적으로 출현
- **텔:** 사라지기 직전 보스 실루엣이 사이안 색으로 잔상을 남김
- **대응:** 잔상 위치에서 벗어나 회피. 정확한 위치 예측이 어려워 고난이도

### P2-4) Cascade Query `Normal`

- **컨셉:** 척추 지느러미를 파동처럼 순서대로 쏘아 플레이어에게 연속 판정
- **대응:** 각 지느러미 타이밍에 맞춰 연속 패링 — 성공 시 그로기 폭발적 누적

### 체력 20% 이하 Climax 패턴

- **컨셉:** 장판 전체가 동시에 생성되며 보스가 보스방 중앙에서 회전 돌진
- **대응:** 장판이 없는 모서리 쪽으로 대피 후 회전이 끝날 때 반격
- **연출:** 화면 전체 사이안 색 과부하 플래시 + 슬로우 모션 예고

### 피격감 / 리액션
- [ ]  Tide Surge 넉백 거리가 전투 공간 밖으로 날아가지 않는가
- [ ]  Data Crush 직격 Knockback 방향이 자연스러운가
- [ ]  Null Field / Transaction Loop 장판 피해가 너무 낮아 무시되지 않는가

### 밸런스
- [ ]  P1 패턴 2개만으로 "읽기 → 패링 → 그로기 → 처형" 루프가 성립하는가
- [ ]  P2 이후 장판 개수 증가로 체감 난이도 상승이 명확히 느껴지는가
- [ ]  그로기 발동까지의 교전 횟수가 6~8회 내외인가
- [ ]  Transaction Loop 장판 3개가 전투 공간 전체를 막지 않는가 (최소 안전지대 확보)

### AI 발동 타이밍
- [ ]  Null Field가 플레이어가 멀리 있을 때도 발동되는가 (Trigger 200~700 확인)
- [ ]  Transaction Loop가 근거리 조건 없이 발동되지 않는가
- [ ]  같은 패턴이 연속으로 발동되는 경우가 없는가 (반복 페널티 동작 확인)
