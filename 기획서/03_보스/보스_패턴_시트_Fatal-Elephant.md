## 3. 공통 규칙

모든 패턴은 아래 3단계 구조를 포함한다.

- **텔(예고):** 동물적 움직임으로 읽히도록. 발을 구르거나, 코(케이블)를 들어올리거나, 몸을 낮추는 모션.
- **위험 구간:** 실제 판정이 발생하는 구간.
- **리커버리:** 대응 성공 시 딜 찬스. Fatal Elephant는 리커버리가 길어 반격 창이 큼.

공격 타입 태그:
- `Normal` — 패링 가능
- `Smash` — 패링 불가, 회피 권장
- `AOE` — 범위기
- `Zone` — 장판/지속 효과

**핵심 디자인 철학:** 느려 보이지만 갑자기 폭발적으로 빠른 패턴이 섞여 있다. "방심 → 직격"의 패턴이 PHP 레거시의 "예상 못한 에러 폭발" 느낌을 표현한다.

## 4. 패턴 발동 철학

쿨타임은 밸런스 안전장치일 뿐, **실제 발동 타이밍은 AI가 상황을 보고 판단**한다.

- 쿨타임 종료 = **Ready 상태** (발동 후보에 포함)
- Serpent.py보다 **반복 페널티 가중치를 낮게** 설정 → 같은 패턴 반복 빈도 소폭 증가로 압박감 유지

## 5. Phase 1 패턴

### P1-1) Legacy Charge `Smash`

> "예고 없이 폭발적으로 돌진. 느린 보스가 갑자기 빨라지는 패턴."

| 항목 | 수치/내용 |
|---|---|
| Trigger 거리 | 전 범위 (300 이상일 때 발동 확률 높음) |
| Cooldown | 6s |
| AttackType | Smash (패링 불가) |
| GroggyDamage | 0 |
| Damage | 50 |
| HitStop | 0.20s |
| ReactionType | Knockback |
| 돌진 속도 | 기본 MoveSpeed × 4 (일시적) |
| 돌진 거리 | Hendel 위치까지 직선 |

**텔 (0.4s)**
- 발을 한 번 크게 구르며 몸을 낮춤
- 눈(PHP 로고 보라색)이 밝아짐
- **텔 모션이 짧아서 처음엔 읽기 어렵다** — 학습 필요

**히트 프레임**
- 돌진 시작 시 Hendel 위치 스냅샷 저장
- 저장된 위치로 직선 돌진 (캡슐 스윕으로 히트 판정)
- 히트 시 Knockback 적용

**리커버리 (1.2s)**
- 돌진 후 관성으로 오버슈트. 벽/경계에 부딪히면 추가 경직 0.5s
- 오버슈트 구간이 주요 딜 타임

**대응 의도**
- 측면으로 회피 → 오버슈트 구간 반격
- 처음엔 텔이 짧아 맞지만, 반복하면 "발 구르기 = 돌진 준비"를 학습

### P1-2) Deprecation Stomp `AOE`

> "발을 내려찍어 광역 충격파 발생. 바닥 예고 데칼 있음."

| 항목 | 수치/내용 |
|---|---|
| Trigger 거리 | < 400 |
| Cooldown | 8s |
| AttackType | AOE (패링 불가) |
| GroggyDamage | 0 |
| Damage | 직격 40 / 충격파 25 |
| HitStop | 0.18s |
| ReactionType | 직격 Knockback / 충격파 Heavy_Hit |
| 충격파 반경 | 500 |

**텔 (0.7s)**
- 한쪽 앞발을 들어올리는 모션
- 바닥에 충격파 예고 원형 데칼 표시 (서서히 채워짐)

**히트 프레임**
- 발 내려찍기 직격 판정 (반경 150)
- 착지 직후 충격파 AOE 확장 (반경 500)

**리커버리 (1.0s)**
- 착지 후 발을 빼는 모션. 긴 후딜로 반격 창 제공.

**대응 의도**
- Serpent.py의 Coil Slam과 비슷한 학습 구조이지만 충격파 반경이 더 넓음
- "예고 원 밖으로 이동"이 기본 대응. 이후 후딜에 반격.

## 6. Phase 2 진입 — Fatal Error

> HP 50% 이하 최초 도달 시 1회 발동

| 항목 | 내용 |
|---|---|
| Trigger | `CurrentHP <= MaxHP * 0.5` 최초 1회 |
| 무적 구간 | 진입 연출 전 구간 (약 4s) |
| BT 처리 | 현재 태스크 Abort → Fatal Error 서브트리 실행 |
| 이후 | P2 전용 서브트리로 전환. MoveSpeed 300 → 420 |

**연출 순서**
```
Fatal Elephant HP 50% 도달
    ↓
BT Abort → 무적 활성화
    ↓
경고등이 모두 적색으로 전환
    ↓
포효 몽타주 재생:
- 케이블들이 전신에서 폭발적으로 퍼져나감
- 서버 팬 소음이 과부하 상태로 커짐
- 보라색 눈이 붉게 변함
    ↓
몸체에서 케이블/케이블 연기 이펙트 강화
이동 속도 증가 (시각적으로 보행 모션이 빨라짐)
    ↓
무적 해제 → P2 BT 활성화
```

## 7. Phase 2 패턴

### P2-1) Fatal Error Rush `Smash`

> "P2 전용. 3연타 돌진. 매 타격 후 방향 전환."

| 항목 | 수치/내용 |
|---|---|
| Trigger 거리 | 전 범위 |
| Cooldown | 10s |
| AttackType | Smash (패링 불가) |
| GroggyDamage | 0 |
| Damage | 1타 30 / 2타 30 / 3타 40 |
| HitStop | 0.12s |
| ReactionType | 1·2타 Heavy_Hit / 3타 Knockback |

**텔 (0.4s)**
- P1 Legacy Charge와 동일한 텔 (발 구르기 + 눈 발광)
- 그러나 이번엔 3타 연속으로 이어짐

**히트 프레임**
- 1타 돌진 후 즉시 Hendel 위치 재계산 → 2타 방향 전환 돌진
- 2타 후 동일하게 3타 방향 전환
- 각 돌진 사이 인터벌: 0.3s

**리커버리 (1.5s)**
- 3타 후 긴 후딜. 주요 딜 타임.

**대응 의도**
- 1타·2타 측면 회피 → 3타 후 딜
- 또는 3타 전부 회피 후 후딜에 큰 딜

---

### P2-2) Overflow `Zone Control`

> "케이블 장판을 전장에 설치. 이동 제한 + 지속 피해."

| 항목 | 수치/내용 |
|---|---|
| Trigger 조건 | Hendel이 근거리(< 250)에서 5초 이상 유지 시 |
| Cooldown | 12s |
| AttackType | Zone |
| GroggyDamage | 0 |
| Damage | 장판 초당 10 (3~4초 지속) |
| 스태미나 디버프 | 장판 위에서 스태미나 회복 딜레이 +1.5s |
| 장판 수 | 최대 4개 동시 |
| 장판 반경 | 각 200 |

**텔 (0.8s)**
- 코(케이블 다발)를 들어올리며 바닥에 케이블을 뿌리는 모션
- 케이블이 설치될 위치에 주황색 경고 마커 표시

**히트 프레임**
- 케이블 장판 생성 (Decal + Collision Box)
- 장판 위에 있으면 지속 피해 + 스태미나 회복 방해

**리커버리 (0.3s)**
- 보스 자체 후딜은 짧음. 장판이 지속 압박을 담당.

**대응 의도**
- 무지성 근접 딜링을 막는 장치
- Serpent.py의 Syntax Venom보다 장판이 더 많고 스태미나 페널티가 강함

## 10. 튜닝 체크리스트

### 텔 / 학습 가능성
- [ ]  Legacy Charge 텔(0.4s)이 처음엔 읽기 어렵지만 반복 시 학습 가능한가
- [ ]  Deprecation Stomp 예고 데칼이 충분히 눈에 띄는가
- [ ]  Fatal Error Rush의 방향 전환이 자연스럽게 연결되는가

### 피격감 / 리액션
- [ ]  Legacy Charge Knockback 방향이 지형 밖으로 날아가지 않는가
- [ ]  Deprecation Stomp AOE 반경(500)이 너무 넓어 회피가 불가능하지 않은가
- [ ]  Fatal Error Rush 3연타 중 회피가 현실적으로 가능한가

### 밸런스
- [ ]  패링 없이 공격 딜링만으로 그로기 누적이 가능한가
- [ ]  P2 이후 체감 난이도 상승이 명확한가 (속도 증가 + 3연타)
- [ ]  Overflow 장판이 전투 공간 전체를 막지 않는가

### AI 발동 타이밍
- [ ]  Legacy Charge가 근거리에서도 발동되지 않는가 (근거리 Trigger 범위 확인)
- [ ]  Overflow가 Hendel이 멀리 있을 때 발동되지 않는가
- [ ]  Fatal Error Rush가 P1에서 발동되지 않는가 (P2 전용 확인)
